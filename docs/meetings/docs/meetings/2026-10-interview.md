# Протокол интервью с заказчиком (Инициация проекта)
Дата: 10 октября 2026 г. · Участники: Аналитик (@shreksons), Заказчик / Преподаватель

## Вопросы и ответы
1. **Какова основная цель системы мониторинга воздуха?**
   — Предоставление наглядной веб-карты показателей качества воздуха (AQI, PM2.5, CO2) в Лос-Анджелесе для информирования населения и эко-служб.
2. **Какие регионы/зоны являются приоритетными?**
   — Район Лос-Анджелеса (штат Калифорния) с акцентом на спальные и промышленные зоны.
3. **Какие источники данных следует использовать?**
   — Открытые API (OpenAQ, US EPA AirNow) и исторические статические дата-сеты на случай сбоев API.
4. **Какие минимальные функции должны войти в MVP?**
   — Интерактивная карта с цветами по уровню AQI, фильтрация по загрязнителям и расчёт средних значений по районам.
5. **Есть ли ограничения по стеку и бюджету?**
   — Разработка выполняется силами студенческой команды без привлечения платных сервисов (используются бесплатные тарифы GitHub, Vercel/GitHub Pages).
6. **Как будет оцениваться воспроизводимость анализа?**
   — Весь пайплайн обработки данных и запуска приложения должен запускаться одной командой или сценарием.
7. **Каковы допустимые отклонения по графику и трудозатратам?**
   — Отклонение по суммарным часам команды не должно превышать 10% от зафиксированного в уставе (252 ч).
8. **В каком виде представляются итоговые результаты?**
   — Защита проекта по этапам, репозиторий с закрытыми Issues/PR и опубликованный релиз v1.0.
